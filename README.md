# 🎴 카드클래시 1.0 — Card Clash

4종족 카드 72종이 등장하는 웹 카드게임. 기존 5차 수정판의 전투·체인·리액션 엔진을 유지하며, 1인 양쪽 조작 모드와 **서버가 상태를 보유하는 2인 실시간 대전 모드**를 제공합니다.

## 게임 실행 모드

- **1인 모드** (`/solo.html`): 기존처럼 혼자 두 명의 카드를 모두 확인하며 조작합니다. 저장, 체크포인트, Undo, 드래그 이동, 덱 편집, 수치 편집을 지원합니다. `app/solo.html` 파일만 별도로 열어도 됩니다.
- **2인 모드** (`/online.html`): 두 브라우저/기기에서 접속해 자동 매칭 또는 6자리 친구 방 코드로 대전합니다. 시작 패·드로우·덱 순서·우선권·효과 처리는 서버가 관리합니다. 상대 플레이어에게는 손패 내용이나 덱 순서를 전송하지 않습니다. 상대 손패 수량과 필드/묘지/공개 기록만 보입니다. 서로 다른 종족뿐 아니라 같은 종족끼리도 각자의 25장 덱으로 경기할 수 있습니다.
- **관리자 밸런스 연구실** (`/admin.html`): 서버 운영자가 비밀 토큰으로 인증한 뒤 카드 비용/기본 공격력/효과 숫자, 후공 추가 에너지를 조정하면 서버 설정을 즉시 저장하고 **진행 중인 온라인 대전에도 반영**합니다.

## 1.0 규칙 변경

- 후공의 첫 턴 충전: **150 ME / 150 TE** (기본 100 + 후공 추가 50).
- 카드 **72종**: 기존 64종에서 종족별 2종씩 추가. 네 종족 모두 18종.
- 랜드: **질풍마 → 돌파 야생마** (효과 유지), **돌격 야생마**(100ME/ATK2000/러시), **함정 민들레**(65ME/ATK1500/필드 파괴 시 적 1장 ATK-1000, 리액션 A라인 소환).
- 오션: **밀물 75TE**(상대 B→A, 리액션 손패 회수), **긴급 출항 110TE**(상대 턴에 패의 고유 보호 몬스터 1장 A라인 특수 소환), **방어벽 80TE**.
- 스카이: **능숙 알바트로스**(65ME/ATK1000, 공격 시 +1000), **일석이조 125TE**(ATK1000 이하의 스카이 몬스터 최대 2장 패에서 A라인 소환, 리액션은 패에서 B라인 소환), **기관총 거위** 기동은 B라인에서만 발동.
- 아더스: **유령 고양이**(50ME/ATK500/스텔스), **마녀여왕의 가호 130TE**(자신 필드 몬스터 1장 턴 종료까지 파괴 방지), **화산 분출 100TE**.
- **긴급 출항**: 공격 선언에 대응해 A라인에 특수 소환된 보호 몬스터는 그 공격 해결 직전에 가로채기 후보가 됩니다. 직접 공격 도중 새 A라인 방어선이 생기면 해당 직접 공격은 취소됩니다.
- **공통 파괴 규칙**: 필드에서 묘지로 가는 모든 이동(제물·자신을 묘지로 보내는 효과·전투·효과)은 파괴로 취급합니다. 마녀여왕의 가호는 이 모든 파괴와 ATK 0 이하의 자동 파괴를 막으며, 패로 귀환/라인 이동은 막지 못합니다. 덱에서 묘지로 가는 기존 리액션은 별도입니다.
- 기존 **25장 단일 종족 기본 덱**을 유지하지만, 1인 및 2인 **덱 편집기에서 혼합 덱을 구성할 수 있도록 확장**했습니다. `🌐 모든 종족 카드 보기`를 선택하면 다른 종족 카드를 넣을 수 있습니다. 기술은 해당 종족 몬스터가 필드에 있어야 사용 가능합니다. 신규 카드는 덱 편집기에서 편성합니다. 기존 질풍마 구성은 돌파 야생마로 대체합니다.
- 네 종족 기본 덱은 이전 대화에서 확정한 25장 구성을 유지합니다. 격류 1장 복귀는 미확정이므로 기본 수량을 임의로 바꾸지 않았습니다.

## 빠르게 로컬 서버 실행하기

Python 3.12 이상 권장. 이 폴더에서:

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
uvicorn server:app --host 127.0.0.1 --port 8000
```

이후 브라우저에서 `http://127.0.0.1:8000` 열기. 휴대폰이나 다른 PC에서도 접속하려면 서버를 외부 접근 가능하게 배포해야 합니다. 개발 중 두 브라우저 창을 띄우면 2인 대전을 시험할 수 있습니다.

관리자 기능을 사용하려면 서버 실행 전에 환경변수 `CARDCLASH_ADMIN_TOKEN`에 **충분히 긴 비밀값**을 설정하세요. 코드를 GitHub에 올릴 때 이 값은 절대로 커밋하지 마세요.

```bash
# macOS / Linux 예시
export CARDCLASH_ADMIN_TOKEN='직접_생성한_길고_무작위인_비밀번호'
uvicorn server:app --host 127.0.0.1 --port 8000
```

```powershell
# Windows PowerShell 예시
$env:CARDCLASH_ADMIN_TOKEN = '직접_생성한_길고_무작위인_비밀번호'
uvicorn server:app --host 127.0.0.1 --port 8000
```

## GitHub → 인터넷 배포

**GitHub Pages만으로 2인 실시간 모드는 실행할 수 없습니다.** GitHub는 코드 저장소로 사용하고, `Dockerfile`을 읽어 24시간 HTTP/WebSocket 서버를 실행하는 Render 또는 Railway에 배포하세요.

1. GitHub에서 `cardclash`라는 새 저장소 생성.
2. 이 압축파일을 풀어 나온 **프로젝트 루트 파일과 `app/` 폴더**를 저장소에 업로드 (ZIP 파일 자체가 아니라 압축 해제한 파일들).
3. Render에서 **New → Web Service → GitHub 저장소 선택 → Runtime: Docker** (또는 Railway에서 **New Project → GitHub Repo**). 루트의 `Dockerfile`을 인식합니다.
4. 호스팅 서비스의 환경변수 `CARDCLASH_ADMIN_TOKEN`에 임의의 긴 비밀값을 저장합니다. `PORT`는 호스팅 서비스가 제공하는 값을 사용합니다.
5. 배포된 HTTPS 주소에 접속하면 두 모드가 작동합니다. 친구에게 주소를 보내 2인 매칭할 수 있습니다.
6. **배포 재시작 후에도 서버 수치 설정을 유지**하려면 영속 볼륨을 `/game/config`에 연결하거나 `CARDCLASH_DATA_DIR`를 볼륨 마운트 경로로 설정합니다. 영속 볼륨이 없다면 배포 재시작 때 서버에서 저장한 수치 변경이 초기화될 수 있습니다.

서버는 하나의 인스턴스로 실행하세요(메모리 기반 방 관리). Chromium을 경기별 격리 페이지로 구동하므로 메모리 사용량을 고려해 충분한 서버 메모리를 확보해야 합니다. 일반적인 무료 정적 호스팅은 이 구조에 적합하지 않습니다.

## 게임 내 수량 및 수치 조정

| 항목 | 1인 모드 | 2인 모드 |
|---|---|---|
| 덱 카드별 수량 0~3장 | 게임 상단 **덱 편집** → 종족별 25장 저장 | 매칭 전 **내 덱 편집** → 저장 |
| 카드 비용·공격력 | **수치 편집** → 즉시 반영 및 브라우저 저장 | **관리자** `/admin.html` → 토큰 인증 후 서버 전체 즉시 반영 |
| 카드 효과에 포함된 숫자 | 수치 편집(효과 키워드 변경은 제한) | 관리자 수치 편집(효과 키워드 변경은 제한) |
| 후공 추가 에너지 | 수치 편집 | 관리자 수치 편집 |

1인 저장은 현재 브라우저의 `localStorage`를 사용합니다. 2인 덱 수량은 각자의 브라우저에 저장되며 매칭 시작 시 서버가 25장/최대 3장 규칙을 검증합니다. **진행 중인 온라인 게임에 새 덱을 주입하는 것은 불가능하고, 덱 변경은 다음 대전부터 적용**됩니다. 카드 수치 변경은 게임 중에도 새 계산에 즉시 적용되지만 이미 지불한 비용이나 해결된 효과를 소급하지 않습니다.

## 구조와 보안

- `app/solo.html` — 72종 카드와 전체 규칙을 가진 기존 브라우저 게임 엔진(로컬 게임).
- `server.py` — FastAPI, WebSocket 매칭/방 코드, 서버 카드 정보 검증, 턴·우선권 권한 검사, 분리된 각 경기의 브라우저 엔진 제어.
- `app/online.html` — 상대 카드 비공개인 온라인 플레이 화면.
- `app/admin.html` — 인증된 관리자만 사용할 수 있는 라이브 밸런스 조정 화면.
- `app/index.html` — 모드 선택 홈.
- `Dockerfile` / `requirements.txt` — 클라우드 서버 실행 환경.

서버는 **모든 손패를 서버에 보관하며**, 사용자에게는 자기 손패만 전송합니다. 공격 타깃과 효과 선택·보호 선택도 서버가 확인합니다. 공개 묘지, 카드 스펙 및 전투 기록은 양쪽에 공개됩니다.

## 1.0 운영 범위 및 주의점

이것은 **소규모 테스트를 위한 첫 온라인 릴리스**입니다. 자동 매칭과 친구 방 접속은 구현되어 있지만 계정/랭킹/관전/AI 대전/게임 재접속/턴 타이머/악성 사용자 제재/영구 전적 DB는 아직 없습니다. 실시간 방은 서버 메모리에 보관되므로 재시작 또는 플레이어 연결 종료 시 대전이 중단됩니다. 따라서 지인 간 시험 플레이부터 권장합니다.

실제 인터넷 배포가 완료되려면 사용자의 GitHub 저장소와 호스팅 서비스가 연결되어야 합니다. 프로젝트 패키지 제공 자체는 공개 사이트 개설이 아닙니다.

## 혼합 덱 운영

매칭/덱 편집 화면에서 선택한 종족은 **덱의 메인 종족 표시와 기본 덱 선택**에 사용됩니다. 편집기에서 다른 종족 카드를 포함해도 됩니다. 각 카드의 종족 자체는 변경되지 않으며, 기술 카드 발동 시 해당 종족 몬스터가 자신의 필드에 반드시 1장 이상 있어야 합니다. 25장과 카드당 최대 3장 제한은 유지됩니다.
