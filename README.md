# 🎴 카드클래시 3.0 — 최종 통합본 (92종)

기존 **GitHub + Render / FastAPI + Playwright** 프로젝트의 구조를 유지한 3.0 버전입니다. 새 HTML 게임이나 새 Render 서비스를 만드는 방식이 아닙니다. **이 소스는 로컬에서 제작·시험한 결과이며 GitHub/Render에 반영하지 않았습니다.**

## 접속 경로

- `/` — 메인 메뉴
- `/solo.html` — 양측 직접 조작 솔로 모드(컴퓨터 AI 아님), 되돌리기·저장·덱 편집
- `/online.html` — 2인 온라인 대전(친구 방 / 자동 매칭)
- `/admin.html` — 관리자 밸런스 도구(서버 관리자 토큰 필요)
- `/api/health` — 서버 상태 및 버전

## 카드 및 룰

- **92종** = 2.5의 84종 + 3.0 신규 8종(각 종족 2종).

- 신규 랜드: **무사 다람쥐, 지진** / 오션: **대왕고래, 넘기기 넙치** / 스카이: **종이 비행기, 전이** / 아더스: **원한 인형, 도굴 고블린**.

## 로컬 실행

1. Python과 Chromium/Playwright 실행 환경을 준비합니다.
2. `pip install -r requirements.txt`
3. `python -m playwright install chromium` (운영체제에 따라 추가 브라우저 의존성 필요)
4. `uvicorn server:app --host 127.0.0.1 --port 8000`
5. 브라우저에서 `http://127.0.0.1:8000/`에 접속합니다.

Docker/Render는 **기존 Dockerfile과 render.yaml을 그대로 유지**합니다. 현재 운영 저장소의 해당 파일을 업데이트한 뒤 기존 배포 프로세스를 사용하십시오. 관리자 밸런스 설정 파일과 브라우저에 저장된 수동 밸런스 오버라이드는 기본값보다 우선할 수 있으므로, 이전 실험 값이 남아 있으면 관리자 도구 또는 브라우저 설정을 확인하십시오.

## 설계·출시 제한

- 빗방울·기생충·불꽃의 매머드·상냥한 크라켄·교활한 크라켄: **3.0 미출시**.
- 게임 서버 상태 저장 및 이름별 덱 저장소의 기존 호환 제약은 유지합니다. 이름별 덱은 브라우저 localStorage에서 관리하고 별도 서버 동기화는 없습니다.
- 코드와 배포를 실제 서비스에 적용하기 전에 현재 운영 중인 GitHub 브랜치와 소스를 비교하고, 실제 플레이로 후속 검증해야 합니다.
